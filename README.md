# Шпион

Веб-игра на Go с общением через WebSocket.

Запуск: `go run .`, затем открыть http://localhost:8080.
В Docker: `docker compose up --build`.

## Ходы и голосование

- Первый живой игрок в порядке входа в комнату спрашивает следующего. Оба видят окно с подсказкой.
- После вопроса и ответа оба нажимают «ОК». Пока подтвердил только один, ход не меняется.
- Отвечавший задаёт следующий вопрос. Последний живой игрок спрашивает первого — это завершает круг.
- В конце круга у всех открывается голосование на 30 секунд. Каждый живой игрок выбирает одного подозреваемого или «Пропустить».
- Игрок выбывает, если получил больше половины голосов всех живых игроков. Пропуски и отсутствие ответа не считаются голосами против кого-либо. Если большинства нет, никто не выбывает.
- После голосования начинается следующий круг среди оставшихся игроков, если одна из сторон ещё не победила.
- При переподключении сохраняются текущий ход, подтверждение «ОК» и уже поданный голос. При временном отключении участника хода очередь ждёт его возвращения; после истечения срока восстановления (5 минут) игрок удаляется и очередь обновляется.
- Шпион может открыть «Места» и выбрать локацию, в том числе из окна своего хода.

## Проверки

```sh
go test ./...
go vet ./...
node --test frontend.test.cjs
```

Серверные проверки включают полный круг и переподключение через реальные WebSocket-соединения. Проверки интерфейса исполняют JavaScript страницы с моделью DOM; они не заменяют визуальную проверку в браузере.
